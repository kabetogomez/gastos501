Sincronización Firebase

Para compartir datos entre dispositivos

1. Ve a console.firebase.google.com

2. Crea un proyecto (sin Analytics)

3. Build → Realtime Database → Create → Test mode

4. Copia la URL

5. Settings → Service Accounts → Database Secrets → Crear

6. Pega URL y secreto en Ajustes. Los 3 celulares usan los mismos.
